发货单打印

新手使用说明

本工作台为电商商家提供「商品建档 → 订单录入 → 发货/退货 → 库存联动 → 统计对账」的一体化闭环管理，数据保存在本机浏览器（localStorage），离线可用，建议定期点击右上角「备份数据」导出 JSON 以防丢失。

一、核心操作流程

  1. 建档商品：进入「商品档案」→ 点「＋新增商品」。填写建档日期、产品名称（唯一）、型号、尺寸、成本价、售价、初始库存、安全库存阈值。单件利润 = 售价 − 成本价，系统自动计算，不可手改。保存后该行即进入商品档案，作为订单选品的关键字。
  2. 录入订单：进入「订单录入」→ 点「＋新增订单」。选择平台来源、填写/自动生成订单编号、选择产品名称后，型号/尺寸/成本价/售价/单件利润自动带出；填写数量后，单品总利润、订单总金额自动核算。
  3. 发货 / 退货：
    • 在订单行点「发货」→ 状态变「已发货完成」，系统自动扣减对应商品库存（数量=下单数量）。若当前库存不足，禁止发货并弹窗提醒。
    • 点「退货」→ 状态变「已退货入库」，系统自动回库对应数量。
    • 「作废」用于取消订单（不触发库存变动）；多品合并单请用相同「订单编号」录入多行，在「合并订单」视图查看整单汇总。

    📊 统计口径：订单状态为【已发货完成、退换处理中】计入统计看板营收与利润；【已退货入库、作废订单】不计入销售额与利润。

  4. 查看统计报表：进入「统计看板」，选择周期（今日/近7天/近30天/本月/半年/全年/指定月份）与平台，查看订单总量、销售总额、总利润、平台占比、销量排行；点「🔄刷新」实时更新，点「导出报表」导出 Excel。

二、各页面功能

页面功能
商品档案商品主数据增删改；低于安全库存自动标红预警；支持导出 Excel。
订单录入订单明细 / 合并订单双视图；选品联动、利润自动算；发货扣库存、退货回库存、超库存拦截；导出 Excel。
库存管理库存台账独立页，实时展示库存、安全库存、预警状态；可勾选「仅看库存不足」。
统计看板多维度自动汇总（今日/7天/30天/月/半年/年），平台占比、销量排行、月度营收趋势。
操作日志永久记录所有操作（含修改前后），不可删除、不可篡改；可按类型筛选、导出。
发货单打印标准发货单/拣货单模板，含订单号、平台、收件信息、产品明细、数量、快递；可直接打印，店铺名可改。

三、业务规则速查

  • 单件利润、单品总利润、订单总金额、发货日期均为系统自动计算/填充字段，已锁定不可手动篡改。
  • 当前库存仅随「发货（扣减）/ 退货（回库）」自动变动；「作废订单」不触发库存变动；如需修正盘点差异请用库存管理盘点调整；编辑商品档案时不可手动改当前库存。
  • 手动修改商品档案里的初始库存不会触发库存联动，也不会自动生成操作日志；库存变动留痕仅来自订单发货、退货、库存管理盘点调整。
  • 订单编号唯一；产品名称唯一；数量须为正整数；成本/售价 ≥ 0。
  • 所有增删改与状态流转均记入操作日志，确保可追溯。

⚠️ 重要提醒：禁止在无痕（隐私）窗口使用本工作台！无痕模式关闭浏览器后数据会被直接清空、无法找回。请定期点击右上角「备份数据」导出 JSON 文件妥善保存；换设备、清理浏览器缓存、重装系统前，务必先备份。数据仅存储在本机浏览器，云端不留存。
